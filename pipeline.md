# AI Builder Pipeline

## Goal
Turn a user's idea into a working software project.

## Pipeline

1. User Request
   - Receive the user's idea.

2. Supervisor AI
   - Understand the request.
   - Decide which AI should work next.
   - Check the results from each AI.

3. Analysis AI
   - Understand exactly what the user wants.
   - Identify requirements.
   - Ask for missing information when necessary.

4. Blueprint AI
   - Design the application.
   - Decide the features.
   - Decide the required files and technology.

5. Builder AI
   - Create the project files.
   - Write the required code.

6. Tester AI
   - Check the generated project.
   - Find errors and missing features.

7. Fixer AI
   - Fix the errors found by Tester AI.
   - Send the project back for testing.

8. Final Output
   - When testing passes, prepare the completed project.
   - Eventually generate an Android APK.

## Rule
The Supervisor AI controls the whole pipeline.
